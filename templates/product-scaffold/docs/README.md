# Docs

Populate this folder from the repo-level templates in
[`/templates`](../../../templates/README.md) — don't write these from
scratch per product:

| File | From |
|---|---|
| `README.md` | `templates/README_TEMPLATE.md` |
| `ARCHITECTURE.md` | `templates/ARCHITECTURE_TEMPLATE.md` |
| `API.md` | `templates/API_DOCS_TEMPLATE.md` |
| `CHANGELOG.md` | `templates/CHANGELOG_TEMPLATE.md` |
| `ONBOARDING.md` | `templates/ONBOARDING_TEMPLATE.md` |
| `TROUBLESHOOTING.md` | `templates/TROUBLESHOOTING_TEMPLATE.md` |
| `decisions/NNNN-*.md` | `templates/ADR_TEMPLATE.md`, one per significant decision |

Full expectations in
[`standards/documentation.md`](../../../standards/documentation.md).
