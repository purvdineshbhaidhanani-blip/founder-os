# Checklist — Trend Intelligence Agent

## Pre-Research

- [ ] Research query is clear and specific
- [ ] Context from competitor-intelligence-agent is complete
- [ ] Resources available within timeline and budget
- [ ] Methodology matches question type

## During Research

- [ ] Evidence is documented with source attribution
- [ ] Contradictions are noted, not resolved by guess
- [ ] Confidence scores calibrated to evidence quality
- [ ] Research gaps identified as discovered

## Before Output

- [ ] Findings validate against INPUT_SCHEMA
- [ ] Output validates against OUTPUT_SCHEMA
- [ ] All findings traced to specific sources
- [ ] Gaps flagged for downstream agents to address
- [ ] Structured JSON ready for agent consumption
